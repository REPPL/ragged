# Ragged v0.8.3 Roadmap - Platform-Specific Installers (Conditional)

**Status:** Conditional (implement only if demand exists)

**Total Hours:** 20-30 hours (AI implementation)

**Focus:** Native platform installers for Windows, macOS, and Linux

**Breaking Changes:** None

**Dependencies:** Requires v0.8.0-v0.8.2 completion (installation foundation and refinements)

**Purpose:** Provide native installer experience (double-click installation) for users who prefer graphical installers over command-line scripts

---

## Overview

Version 0.8.3 creates platform-specific installers for Windows (.exe), macOS (.pkg), and Linux (.deb, .rpm, AppImage), transforming ragged installation from "run shell script" to "double-click to install" with full system integration (Start Menu, Applications folder, PATH, uninstall entries).

**Rationale for Conditional Status:** Platform-specific installers add significant maintenance burden (packaging, signing, distribution) and may not be needed if the shell script installer (v0.8.1) satisfies most users. Implementation depends on validated demand.

### Decision Criteria

**Implement v0.8.3 if:**
- ✓ User requests for native installers (>20 independent requests)
- ✓ Windows user adoption significant (>30% of users)
- ✓ Enterprise adoption requires MSI/pkg installers
- ✓ Shell script installer proves insufficient (<80% success rate)
- ✓ App store distribution desired (Microsoft Store, Mac App Store)

**Skip v0.8.3 if:**
- ✗ Shell script installer satisfies most users (<10 native installer requests)
- ✗ Resource constraints (focus on other priorities)
- ✗ Technical users dominate (comfortable with command-line)
- ✗ Signing certificates expensive or unavailable

**Decision Point:** After v0.8.2 release and 2-3 weeks of user feedback analysis

---

## Problem Statement

**Current Installation (Post-v0.8.2):**
```bash
# Shell script installation
curl -sSL https://install.ragged.ai | sh

# Issues for non-technical users:
- Command-line intimidating
- Windows users unfamiliar with PowerShell
- No GUI during installation
- Not discoverable in app stores
- No double-click installation
- Manual PATH setup on some platforms
```

### Target Outcomes

**After v0.8.3 Implementation:**
- ✅ Windows: ragged-installer.exe with GUI wizard
- ✅ macOS: ragged-installer.pkg with standard macOS installation flow
- ✅ Linux: .deb (Ubuntu/Debian), .rpm (Fedora/RHEL), AppImage (universal)
- ✅ System integration: Start Menu/Applications, PATH, uninstall entries
- ✅ Code signing: Installers signed and notarized
- ✅ Auto-update capability (optional)
- ✅ Silent install mode for enterprises

## PLATFORM-001: Windows Installer (.exe) (6-8 hours)

**Problem:** Windows users expect .exe installers; shell scripts unfamiliar and intimidating.

**Implementation:**

1. **Choose installer framework** [1-1.5 hours]
   - **Inno Setup (recommended):**
     - Free, widely used (Python, VSCode use it)
     - Scriptable, version control friendly
     - Supports custom pages, silent install
   - **WiX Toolset (alternative):**
     - MSI format (enterprise-friendly)
     - More complex, better Windows integration
   - Decision: Inno Setup for initial version (easier), WiX for enterprise if needed

2. **Create Inno Setup script** [2.5-3 hours]
   - **Installer configuration:**
     ```ini
     [Setup]
     AppName=Ragged
     AppVersion=0.8.3
     AppPublisher=Ragged Project
     DefaultDirName={autopf}\Ragged
     DefaultGroupName=Ragged
     OutputBaseFilename=ragged-installer-windows
     Compression=lzma2
     SolidCompression=yes
     ArchitecturesInstallIn64BitMode=x64
     PrivilegesRequired=admin
     ```

   - **Files to include:**
     - ragged binary (Python bundled with PyInstaller or cx_Freeze)
     - Dependencies (Docker Desktop installer, Ollama installer)
     - Configuration templates
     - Documentation (README, LICENSE)

   - **Custom installation wizard pages:**
     - Welcome page
     - License agreement (GPL-3.0)
     - Installation directory selection
     - Component selection:
       - ☑ Ragged core (required)
       - ☑ Docker Desktop (if not installed)
       - ☑ Ollama (if not installed)
       - ☑ Desktop shortcut
       - ☑ Start Menu entries
     - Configuration page (model selection, auth on/off)
     - Progress page
     - Finish page with "Launch Ragged" checkbox

   - **Post-install tasks:**
     - Add ragged to PATH
     - Create desktop shortcut
     - Create Start Menu entries
     - Register uninstaller in "Add/Remove Programs"
     - Optionally launch ragged after install

3. **Implement dependency bundling** [1.5-2 hours]
   - Bundle Python runtime (no external Python required)
   - Include pre-downloaded installers:
     - Docker Desktop for Windows
     - Ollama for Windows
   - Or download during installation (with progress bar)
   - Handle already-installed dependencies (skip if detected)

4. **Add code signing** [0.5-1 hour]
   - Obtain code signing certificate (e.g., DigiCert, Sectigo)
   - Sign installer executable: `signtool sign /f cert.pfx ragged-installer.exe`
   - Prevents Windows SmartScreen warnings
   - Note: Certificates cost $100-$500/year

5. **Test installer** [0.5-1 hour]
   - Test on fresh Windows 10, Windows 11
   - Test silent install: `ragged-installer.exe /SILENT`
   - Test uninstall
   - Verify PATH updated
   - Verify shortcuts work

**Files:**
- `installers/windows/ragged.iss` (new - Inno Setup script, ~300 lines)
- `installers/windows/bundle.py` (new - bundle Python + deps, ~200 lines)
- `.github/workflows/build-windows-installer.yml` (new - CI/CD, ~150 lines)
- `docs/installation/windows-installer.md` (new - documentation, ~100 lines)

**Success Criteria:**
- Installer works on Windows 10, 11 (64-bit)
- Silent install mode works for enterprises
- Uninstaller removes all traces
- Code signed (no SmartScreen warnings)
- Installation time <15 minutes (including dependencies)

## PLATFORM-002: macOS Package (.pkg) (5-7 hours)

**Problem:** macOS users expect .pkg installers or Homebrew; shell scripts less familiar.

**Implementation:**

1. **Create .pkg installer** [2-2.5 hours]
   - Use `pkgbuild` and `productbuild` (macOS built-in tools)
   - Package structure:
     - ragged binary → `/usr/local/bin/ragged`
     - Configuration templates → `/usr/local/share/ragged/`
     - Documentation → `/usr/local/share/doc/ragged/`
   - Pre-install script:
     - Check macOS version (≥11.0)
     - Check disk space
     - Detect existing installation
   - Post-install script:
     - Install Homebrew (if not present)
     - Install Docker Desktop via Homebrew
     - Install Ollama via Homebrew
     - Run ragged setup wizard

2. **Add Homebrew cask** [1.5-2 hours]
   - Create Homebrew cask formula:
     ```ruby
     cask "ragged" do
       version "0.8.3"
       sha256 "..."

       url "https://github.com/ragged/ragged/releases/download/v#{version}/ragged-#{version}.pkg"
       name "Ragged"
       desc "Privacy-first RAG for personal knowledge management"
       homepage "https://ragged.ai"

       pkg "ragged-#{version}.pkg"

       uninstall pkgutil: "ai.ragged.ragged"
     end
     ```
   - Submit to Homebrew Cask repository (community process)
   - Enable installation: `brew install --cask ragged`

3. **Add code signing and notarization** [1-1.5 hours]
   - Obtain Apple Developer ID certificate ($99/year)
   - Sign .pkg: `productsign --sign "Developer ID Installer" ragged.pkg ragged-signed.pkg`
   - Notarize with Apple:
     ```bash
     xcrun notarytool submit ragged-signed.pkg \
       --apple-id user@example.com \
       --password app-specific-password \
       --team-id TEAMID
     ```
   - Staple notarization: `xcrun stapler staple ragged-signed.pkg`
   - Prevents Gatekeeper warnings

4. **Test installer** [0.5-1 hour]
   - Test on fresh macOS 11, 12, 13, 14
   - Test .pkg installer (GUI and command-line)
   - Test Homebrew cask installation
   - Verify uninstall: `pkgutil --forget ai.ragged.ragged`

**Files:**
- `installers/macos/build-pkg.sh` (new - pkgbuild script, ~200 lines)
- `installers/macos/Ragged.rb` (new - Homebrew cask, ~50 lines)
- `.github/workflows/build-macos-installer.yml` (new - CI/CD, ~150 lines)
- `docs/installation/macos-installer.md` (new - documentation, ~100 lines)

**Success Criteria:**
- .pkg installer works on macOS 11-14
- Homebrew cask available
- Code signed and notarized (no Gatekeeper warnings)
- Uninstaller removes all traces
- Installation time <10 minutes

## PLATFORM-003: Linux Packages (.deb, .rpm, AppImage) (5-7 hours)

**Problem:** Linux users expect native packages from package managers; shell scripts acceptable but less integrated.

**Implementation:**

1. **Create .deb package (Ubuntu/Debian)** [1.5-2 hours]
   - Use `dpkg-deb` to create package
   - Package metadata (`control` file):
     ```
     Package: ragged
     Version: 0.8.3
     Architecture: amd64
     Depends: python3 (>= 3.10), docker.io (>= 20.10)
     Maintainer: Ragged Team <support@ragged.ai>
     Description: Privacy-first RAG for personal knowledge management
     ```
   - Post-install script:
     - Add user to docker group: `usermod -aG docker $USER`
     - Install Ollama (download from ollama.ai)
     - Start services
   - Install to:
     - `/usr/bin/ragged` (binary)
     - `/usr/share/ragged/` (config templates)
     - `/etc/ragged/` (system config)
   - Test: `sudo dpkg -i ragged_0.8.3_amd64.deb`

2. **Create .rpm package (Fedora/RHEL)** [1.5-2 hours]
   - Use `rpmbuild` to create package
   - RPM spec file:
     ```spec
     Name: ragged
     Version: 0.8.3
     Release: 1
     Summary: Privacy-first RAG system
     License: GPL-3.0
     Requires: python3 >= 3.10, docker >= 20.10

     %description
     Privacy-first RAG for personal knowledge management

     %post
     usermod -aG docker $USER
     systemctl start docker
     ```
   - Test: `sudo rpm -i ragged-0.8.3-1.x86_64.rpm`

3. **Create AppImage (universal Linux)** [1.5-2 hours]
   - Bundle all dependencies in single file
   - No installation required (portable)
   - Use `linuxdeploy` or `appimagetool`
   - AppImage advantages:
     - Works on any Linux distro
     - No root required
     - Portable (run from USB)
   - Test on Ubuntu, Fedora, Arch

4. **Set up package repositories** [0.5-1 hour]
   - Host .deb repository (apt)
   - Host .rpm repository (yum/dnf)
   - Sign packages with GPG key
   - Users can add repository:
     ```bash
     # Ubuntu/Debian
     echo "deb https://packages.ragged.ai/deb stable main" | sudo tee /etc/apt/sources.list.d/ragged.list
     wget -qO - https://packages.ragged.ai/gpg | sudo apt-key add -
     sudo apt update && sudo apt install ragged

     # Fedora/RHEL
     sudo dnf config-manager --add-repo https://packages.ragged.ai/rpm/ragged.repo
     sudo dnf install ragged
     ```

**Files:**
- `installers/linux/build-deb.sh` (new - .deb builder, ~200 lines)
- `installers/linux/build-rpm.sh` (new - .rpm builder, ~200 lines)
- `installers/linux/build-appimage.sh` (new - AppImage builder, ~150 lines)
- `.github/workflows/build-linux-packages.yml` (new - CI/CD, ~200 lines)
- `docs/installation/linux-packages.md` (new - documentation, ~150 lines)

**Success Criteria:**
- .deb works on Ubuntu 20.04, 22.04, 24.04, Debian 11, 12
- .rpm works on Fedora 38+, RHEL 8+
- AppImage works on major distros
- Package repositories accessible
- Installation via package manager succeeds

## PLATFORM-004: System Integration (3-4 hours)

**Problem:** Installed ragged not well-integrated with system (missing from menus, not in PATH).

**Implementation:**

1. **Add to system PATH** [0.5-1 hour]
   - **Windows:** Add to System PATH (registry)
   - **macOS/Linux:** Symlink to `/usr/local/bin/` (already in PATH)
   - Verify: User can type `ragged` anywhere

2. **Create desktop shortcuts** [1-1.5 hours]
   - **Windows:**
     - Start Menu entry: `%ProgramData%\Microsoft\Windows\Start Menu\Programs\Ragged\`
     - Desktop shortcut (optional, user choice)
     - Shortcuts launch WebUI: `ragged webui --open`
   - **macOS:**
     - Applications folder entry: `/Applications/Ragged.app`
     - Launchpad icon
     - Dock integration (optional)
   - **Linux:**
     - Desktop entry: `/usr/share/applications/ragged.desktop`
     ```ini
     [Desktop Entry]
     Name=Ragged
     Comment=Privacy-first RAG system
     Exec=/usr/bin/ragged webui --open
     Icon=/usr/share/pixmaps/ragged.png
     Terminal=false
     Type=Application
     Categories=Utility;Development;
     ```

3. **Add uninstall entries** [0.5-1 hour]
   - **Windows:** Register in "Add/Remove Programs"
   - **macOS:** Uninstall via `pkgutil --forget` or drag to Trash
   - **Linux:** Uninstall via package manager: `apt remove ragged`

4. **Add file associations (optional)** [0.5-1 hour]
   - Associate `.ragged` files with ragged
   - Right-click context menu: "Open with Ragged"
   - Drag-and-drop onto ragged icon to ingest

**Files:**
- `installers/common/system_integration.py` (new - PATH, shortcuts, ~250 lines)
- `installers/common/ragged.desktop` (new - Linux desktop entry, ~20 lines)
- `installers/common/assets/` (new - icons, logos, ~5 files)

**Success Criteria:**
- ragged accessible from any terminal (in PATH)
- Application appears in Start Menu/Applications/Launcher
- Uninstall entries correct
- File associations work (if implemented)
- Icons display correctly

## Known Risks

- **Code signing cost:** Certificates expensive ($99-$500/year) (mitigate: budget for certificates, consider open-source signing services)
- **Maintenance burden:** Platform installers require ongoing updates (mitigate: automate builds in CI/CD, test extensively)
- **Platform fragmentation:** Supporting many Linux distros complex (mitigate: focus on major distros, provide AppImage as fallback)
- **App store approval:** Submission to Microsoft Store/Mac App Store may be rejected (mitigate: read guidelines carefully, provide excellent documentation)
