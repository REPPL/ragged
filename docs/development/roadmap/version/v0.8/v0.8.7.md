# Ragged v0.8.7 Roadmap - Installation Documentation Excellence

**Status:** Planned

**Total Hours:** 20-30 hours (AI implementation)

**Focus:** Comprehensive installation documentation, troubleshooting, tutorials, and knowledge base

**Breaking Changes:** None

**Dependencies:** Requires v0.8.0-v0.8.6 completion (entire installation system)

**Purpose:** Ensure installation documentation is comprehensive, accessible, and resolves 90%+ of user issues without support intervention

---

## Overview

Version 0.8.7 delivers comprehensive documentation for the installation system, covering detailed installation guides for all platforms, troubleshooting knowledge base, video tutorials, quick start guides, and FAQ. This version ensures users can successfully install ragged and resolve issues independently.

### Problem Statement

**Current Documentation Gaps:**
- Installation guides incomplete (missing platform-specific details)
- Troubleshooting scattered (no centralised knowledge base)
- No video tutorials (visual learners underserved)
- Quick start missing (users want "just get it running")
- FAQ non-existent (common questions unanswered)
- Error messages not documented (users search but find nothing)
- Advanced scenarios undocumented (embedded mode, enterprise setup)

### Target Outcomes

**After v0.8.7 Implementation:**
- ✅ Comprehensive installation guides (Windows, macOS, Linux)
- ✅ Troubleshooting knowledge base (90%+ issues documented)
- ✅ Video tutorials (installation walkthrough, common issues)
- ✅ Quick start guide (<5 minutes to running)
- ✅ FAQ with 50+ questions answered
- ✅ Searchable documentation (find answers quickly)
- ✅ Community contribution framework (users add solutions)

## INSTALL-DOC-002: Troubleshooting Knowledge Base (5-7 hours)

**Problem:** Troubleshooting scattered; no centralised knowledge base.

**Implementation:**

1. **Create troubleshooting guide structure** [1-1.5 hours]
   - Categories:
     - **Prerequisites** (Docker, Python, Ollama issues)
     - **Network** (port conflicts, firewall, proxy)
     - **Permissions** (file access, sudo, SELinux)
     - **Resources** (disk space, memory, CPU)
     - **Services** (startup failures, crashes)
     - **Platform-specific** (Windows, macOS, Linux)
   - Each issue documented:
     - Symptom (error message, behaviour)
     - Cause (why it happens)
     - Solution (step-by-step fix)
     - Prevention (avoid in future)

2. **Document common issues** [2.5-3.5 hours]
   - 50+ common issues documented:

   **Example 1: Port Conflict**
   ```markdown
   ### Port 8000 Already in Use

   **Symptom:**
   ```
   Error: Failed to start FastAPI backend
   Port 8000 is already in use by process 12345 (node)
   ```

   **Cause:**
   Another application is using port 8000, preventing ragged from starting.

   **Solution:**
   1. Identify process using port:
      ```bash
      # Linux/macOS
      lsof -i :8000

      # Windows
      netstat -ano | findstr :8000
      ```
   2. Stop the conflicting process:
      ```bash
      kill -9 12345  # Replace with actual PID
      ```
   3. Or use alternative port:
      ```bash
      ragged config set server.port 8080
      ```
   4. Restart ragged:
      ```bash
      ragged restart
      ```

   **Prevention:**
   - Use ragged health check before installation
   - Configure alternative ports if defaults unavailable
   ```

   **Example 2: Permission Denied**
   ```markdown
   ### Permission Denied: Cannot Create Directory

   **Symptom:**
   ```
   Error: Permission denied: '/Users/username/.ragged/'
   ```

   **Cause:**
   Ragged directory owned by root (installed with sudo) or insufficient permissions.

   **Solution:**
   1. Fix ownership:
      ```bash
      sudo chown -R $USER:$USER ~/.ragged/
      ```
   2. Fix permissions:
      ```bash
      chmod 700 ~/.ragged/
      ```
   3. Retry installation:
      ```bash
      ragged install --resume
      ```

   **Prevention:**
   - Never run installation with `sudo`
   - Run as regular user
   ```

   - More issues: Docker Desktop not found, Ollama service not starting, disk full, memory exhausted, network timeout, HTTPS certificate errors, etc.

## INSTALL-DOC-005: FAQ & Common Questions (3-4 hours)

**Problem:** Common questions unanswered; users must search or ask support.

**Implementation:**

1. **Collect common questions** [0.5-1 hour]
   - Review GitHub issues, Discord/forum posts, support tickets
   - Identify 50+ frequently asked questions
   - Categorise: Installation, Configuration, Troubleshooting, Usage, Advanced

2. **Write FAQ answers** [2-2.5 hours]
   - Answer each question comprehensively
   - Examples:

   **Installation Questions:**
   ```markdown
   **Q: Do I need to install Docker Desktop?**
   A: For most users, yes. Docker Desktop provides Docker and Docker Compose, which ragged uses to run ChromaDB. However, if you prefer Docker-free installation, you can use embedded mode (v0.8.4) by running: `ragged install --mode embedded`

   **Q: Which Ollama model should I choose?**
   A: Depends on your RAM:
   - <8GB RAM: llama3.2:3b (fast, lightweight)
   - 8-16GB RAM: llama3.2:8b (balanced)
   - 16GB+ RAM: mistral or llama3:70b (most capable)

   Start with llama3.2:3b and upgrade if needed.

   **Q: Can I install ragged without admin/sudo?**
   A: Yes! Ragged installs to your user directory (~/.ragged/) and doesn't require admin rights. However, installing dependencies (Docker, Ollama) may require admin rights initially.

   **Q: How long does installation take?**
   A: Typically 5-10 minutes, depending on:
   - Internet speed (downloading Docker, Ollama)
   - Whether dependencies already installed
   - System performance

   **Q: Can I install ragged offline?**
   A: Yes, see [Offline Installation Guide](./installation/offline.md). You'll need to pre-download all dependencies on a machine with internet access.
   ```

   **Troubleshooting Questions:**
   ```markdown
   **Q: Installation failed with "Port 8000 already in use". What do I do?**
   A: Another application is using port 8000. Find and stop it:
   ```bash
   # Find process
   lsof -i :8000  # macOS/Linux
   netstat -ano | findstr :8000  # Windows

   # Stop process (replace 12345 with actual PID)
   kill -9 12345
   ```
   Or use alternative port: `ragged config set server.port 8080`

   **Q: Docker Desktop won't start on Windows. Help!**
   A: Common causes:
   1. WSL 2 not installed: Run `wsl --install` in PowerShell (admin)
   2. Virtualization disabled in BIOS: Enable VT-x/AMD-V
   3. Hyper-V conflicts: Disable VirtualBox/VMware

   See [Windows Troubleshooting](./troubleshooting/platform-specific.md#windows) for details.
   ```

   **Configuration Questions:**
   ```markdown
   **Q: Where is ragged installed?**
   A: ~/.ragged/ (your user home directory)
   - Documents: ~/.ragged/documents/
   - Config: ~/.ragged/config.yaml
   - Logs: ~/.ragged/logs/

   **Q: How do I change the default model?**
   A: `ragged config set llm.model llama3.2:8b`

   **Q: Can I use ragged without the WebUI?**
   A: Yes! Ragged has a full-featured CLI. Install with: `ragged install --no-webui`
   ```

3. **Add searchable FAQ index** [0.5-1 hour]
   - Full-text search across FAQ
   - Tag-based filtering (installation, troubleshooting, etc.)
   - "Related questions" links
