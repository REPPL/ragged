## Features

### OPTIMISE-003: Domain Adaptation (25-35 hours)

**Purpose:** Adapt retrieval and processing to domain-specific characteristics for improved accuracy with specialised content.

#### Supported Domains

**1. Technical/Engineering:**
- Programming languages, frameworks, APIs
- Software architecture, design patterns
- DevOps, cloud infrastructure
- Examples: "Kubernetes ingress controller", "React hooks lifecycle"

**2. Medical/Healthcare:**
- Medical terminology, diagnoses, treatments
- Pharmaceutical names, dosages
- Anatomy, procedures
- Examples: "myocardial infarction", "acetylsalicylic acid 81mg"

**3. Legal:**
- Legal terminology, case citations
- Statutes, regulations
- Contract language
- Examples: "habeas corpus", "42 U.S.C. § 1983"

**4. Academic/Research:**
- Scientific terminology, methodologies
- Citations, paper references
- Research domain jargon
- Examples: "stochastic gradient descent", "p-value < 0.05"

**5. General (Default):**
- Everyday language
- Mixed-domain content
- Fallback for unrecognised domains

#### Implementation Phases

**Phase 1: Domain Detection (8-12h)**
- Document content analysis for domain signals
- Keyword-based domain classifier
- Domain confidence scoring
- Multi-domain document handling
- Domain tagging in metadata

**Phase 2: Terminology Management (10-15h)**
- Domain-specific dictionaries (JSON files per domain)
- Synonym expansion per domain
- Abbreviation/acronym handling
- Medical terminology normalisation (e.g., "MI" → "myocardial infarction")
- Legal citation parsing and normalisation
- Technical abbreviation expansion (e.g., "K8s" → "Kubernetes")

**Phase 3: Domain-Aware Retrieval (7-8h)**
- Query expansion per domain
- Domain-weighted scoring adjustments
- Cross-domain fallback strategies
- Domain hint integration with classification (v0.6.1)
- Domain-aware reranking

#### API Design

```python
from src.optimisation import DomainAdapter, TerminologyExpander

# Initialise domain adapter
adapter = DomainAdapter()

# Detect domain from document
document_text = "Kubernetes provides ingress controllers for HTTP routing..."
domain = adapter.detect_domain(document_text)
print(domain.primary)       # "technical"
print(domain.confidence)    # 0.92
print(domain.keywords)      # ["kubernetes", "ingress", "http"]

# Expand query with domain terminology
expander = TerminologyExpander(domain="technical")
query = "K8s ingress config"
expanded = expander.expand(query)
print(expanded.terms)       # ["kubernetes", "ingress", "configuration", "K8s"]
print(expanded.synonyms)    # {"K8s": ["kubernetes"], "config": ["configuration", "setup"]}

# Domain-aware retrieval
from src.optimisation import DomainRetrieval
retrieval = DomainRetrieval(domain="technical")
results = retrieval.search(query="K8s ingress config", top_k=10)
```

#### Domain Detection Logic

**Keyword-Based Classification:**

```python
# technical.json (excerpt)
{
  "keywords": ["api", "function", "class", "kubernetes", "docker", "react", "python"],
  "patterns": ["\\w+\\.\\w+\\(\\)", "def \\w+", "class \\w+"],
  "weight": 1.0
}

# medical.json (excerpt)
{
  "keywords": ["patient", "diagnosis", "treatment", "mg", "dosage", "symptom"],
  "patterns": ["\\d+mg", "\\d+/\\d+ mmHg"],
  "weight": 1.0,
  "abbreviations": {
    "MI": "myocardial infarction",
    "HTN": "hypertension",
    "COPD": "chronic obstructive pulmonary disease"
  }
}
```

**Detection Algorithm:**
1. Tokenise document text
2. Count keyword matches per domain
3. Apply pattern matching (regex)
4. Calculate domain scores (weighted)
5. Select primary domain (highest score)
6. Assign confidence (score / total_tokens)

#### Terminology Expansion Examples

**Technical Domain:**
- Input: "K8s ingress config"

- Synonyms: K8s ↔ Kubernetes, config ↔ configuration

**Medical Domain:**

**Academic Domain:**

## Security Considerations

### Input Validation

**Domain Detection Input:**
- Maximum document length for domain detection: 100,000 characters
- Strip control characters before analysis
- Validate text encoding (UTF-8)
- Prevent regex DoS with pattern complexity limits

**Query Expansion Input:**
- Maximum query length: 10,000 characters
- Sanitise terminology dictionary inputs
- Prevent injection via malicious synonyms
- Validate expanded query length (prevent explosion)

**Dictionary Injection Prevention:**
- Whitelist domain dictionary files
- Validate JSON schema of dictionaries
- No dynamic dictionary loading from user input
- Sanitise dictionary paths (prevent path traversal)

### Resource Limits

**Domain Detection Limits:**
- Maximum processing time: 500ms per document
- Maximum keywords per domain: 10,000
- Maximum patterns per domain: 100
- Timeout enforcement

**Terminology Expansion Limits:**
- Maximum expansions per term: 5
- Maximum query length after expansion: 50,000 characters
- Prevent expansion loops (A→B→A)
- Memory limits for expansion cache

### Rate Limiting

**Per-User Limits:**
- Domain detection: 100 requests/minute
- Query expansion: 200 requests/minute
- Dictionary operations: 50 requests/minute

### Security Testing

- [ ] Domain detection injection tests (malicious document content)
- [ ] Query expansion injection tests (crafted queries to exploit expansion)
- [ ] Dictionary path traversal tests (prevent loading arbitrary files)
- [ ] Resource exhaustion tests (very long documents, expansion loops)
- [ ] Rate limiting enforcement tests
- [ ] Regex DoS tests (catastrophic backtracking patterns)

## Configuration

### Domain Adaptation Settings

```yaml
# config.yml
domain_adaptation:
  enabled: true
  default_domain: "general"

  detection:
    confidence_threshold: 0.6  # Minimum confidence for domain assignment
    multi_domain_threshold: 0.4  # Assign multiple domains if scores close
    max_processing_time_ms: 500
    cache_domain_detections: true
    cache_ttl_seconds: 3600

  terminology:
    expand_queries: true
    expand_abbreviations: true
    max_expansions_per_term: 5
    max_expanded_query_length: 50000
    expansion_timeout_ms: 50

  retrieval:
    domain_weighted_scoring: true
    cross_domain_fallback: true
    domain_score_boost: 1.2  # Boost score for matching domain

  dictionaries:
    path: "data/domain_dictionaries/"
    preload_on_startup: true
    domains: ["technical", "medical", "legal", "academic"]

  security:
    max_document_length: 100000
    max_patterns_per_domain: 100
    regex_timeout_ms: 100
```
