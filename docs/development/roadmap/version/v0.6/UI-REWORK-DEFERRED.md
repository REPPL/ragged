# v0.6.7-v0.6.10: Modern Web UI - Deferred

**Status:** Deferred to future release

**Reason:** The planned Svelte UI rework (v0.6.7-v0.6.10) represents a major frontend rewrite that requires:
- Dedicated UI/UX design phase
- Svelte 5 setup and configuration
- Component library development
- Integration testing with existing backend
- User testing and feedback

**Current State:**
- Existing Gradio UI functional (v0.6.0)
- Backend APIs complete and ready for new UI
- Streaming support available (v0.6.5)
- Analytics available (v0.6.6)

**Recommendation:**
Complete v0.6.x optimisation series first (v0.6.11-v0.6.15), then dedicate focused development time to UI rework in v0.7.x or later.

**Versions Affected:**
- v0.6.7: Svelte 5 Setup
- v0.6.8: Component Library
- v0.6.9: Core UI Implementation
- v0.6.10: UI Polish & Features

**Alternative Approach:**
Continue with Gradio UI for v0.6.x, implement Svelte UI as v0.7.0 major release with proper design and testing phases.
