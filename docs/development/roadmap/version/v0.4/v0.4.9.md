#### Security Issue Categories

**Path Traversal** (HIGH priority):
- Review all file path handling
- Validate user-provided paths
- Use `pathlib.Path().resolve()` to prevent `..` attacks
- Ensure paths stay within `~/.ragged/`

**Code Injection** (HIGH priority):
- Review all `eval()`, `exec()` usage (should be zero)
- Validate plugin code execution
- Sanitise all user inputs before processing
- Parameterise all database queries

**Dependency Vulnerabilities** (MEDIUM priority):
- Update vulnerable dependencies
- Pin versions for security
- Document known vulnerabilities with workarounds
- Create dependency security policy

**Secrets Management** (MEDIUM priority):
- Audit for hardcoded secrets
- Validate `.env` file permissions (0600)
- Check for secrets in logs
- Ensure no secrets in error messages

**Input Validation** (MEDIUM priority):
- Review all CLI argument parsing
- Validate API inputs
- Sanitise file uploads
- Check for SQL/NoSQL injection vectors

#### Security Fixes Implementation

```python
# BEFORE (Path Traversal Vulnerability)
def read_document(filename: str) -> str:
    """VULNERABLE: Allows ../../../etc/passwd"""
    path = os.path.join("~/.ragged/documents", filename)
    with open(path) as f:
        return f.read()

# AFTER (Secure Path Handling)
def read_document(filename: str) -> str:
    """SECURE: Validates path stays within allowed directory."""
    base_dir = Path("~/.ragged/documents").expanduser().resolve()
    requested_path = (base_dir / filename).resolve()

    # Ensure path is within base directory
    if not requested_path.is_relative_to(base_dir):
        raise SecurityError(f"Path traversal attempt: {filename}")

    with open(requested_path) as f:
        return f.read()


# BEFORE (Command Injection Vulnerability)
def run_plugin(plugin_name: str, args: str) -> str:
    """VULNERABLE: Allows shell injection"""
    command = f"python ~/.ragged/plugins/{plugin_name}.py {args}"
    result = subprocess.run(command, shell=True, capture_output=True)
    return result.stdout.decode()

# AFTER (Secure Command Execution)
def run_plugin(plugin_name: str, args: list[str]) -> str:
    """SECURE: Uses argument list, no shell=True."""
    # Validate plugin name (no path traversal)
    if not plugin_name.isidentifier():
        raise SecurityError(f"Invalid plugin name: {plugin_name}")

    plugin_path = Path("~/.ragged/plugins").expanduser() / f"{plugin_name}.py"
    plugin_path = plugin_path.resolve()

    # Ensure within plugins directory
    plugins_dir = Path("~/.ragged/plugins").expanduser().resolve()
    if not plugin_path.is_relative_to(plugins_dir):
        raise SecurityError(f"Plugin path traversal: {plugin_name}")

    # Run with argument list (no shell)
    result = subprocess.run(
        ["python", str(plugin_path)] + args,
        capture_output=True,
        text=True,
        timeout=30
    )
    return result.stdout


# BEFORE (SQL Injection Vulnerability)
def get_interactions(persona: str, topic: str) -> list:
    """VULNERABLE: SQL injection possible"""
    query = f"SELECT * FROM interactions WHERE persona='{persona}' AND topic LIKE '%{topic}%'"
    return db.execute(query).fetchall()

# AFTER (Parameterised Queries)
def get_interactions(persona: str, topic: str) -> list:
    """SECURE: Parameterised query prevents injection."""
    query = """
        SELECT * FROM interactions
        WHERE persona = ? AND topic LIKE ?
    """
    return db.execute(query, (persona, f"%{topic}%")).fetchall()
```

### 3. Architecture Pattern Enforcement (3h)

Enforce consistent architectural patterns throughout codebase.

**Patterns to Enforce**:

1. **Dependency Injection**:
   - All services use constructor injection
   - No global state
   - Clear dependency graphs

2. **Interface Segregation**:
   - Small, focused interfaces
   - Clients depend on abstractions
   - Implementation details hidden

3. **Plugin Architecture**:
   - All extensions use plugin system
   - No hardcoded extensions
   - Clear plugin lifecycle

4. **Error Handling**:
   - Consistent exception hierarchy
   - Proper error propagation
   - Meaningful error messages

**Example Enforcement**:
```python
# BEFORE: Inconsistent dependency management
class MemorySystem:
    def __init__(self):
        self.db = sqlite3.connect("~/.ragged/memory.db")  # Hardcoded
        self.vector_store = ChromaDB()  # Hardcoded

# AFTER: Dependency injection
class MemorySystem:
    def __init__(
        self,
        db: Database,
        vector_store: VectorStore

        self.vector_store = vector_store
```
