### DEV-002: Just Task Runner (3-4 hours)

**Priority:** MEDIUM
**Category:** Developer Experience

**Goal:** Simplify common development tasks with modern task runner

**Implementation:**

1. **Create Justfile** (2h)
   - Common tasks (setup, install, test, clean)
   - Docker commands (docker-up, docker-down, docker-logs)
   - Documentation tasks (docs-serve, docs-build)
   - Release tasks (version-bump, publish)

2. **Documentation** (1h)
   - just installation guide
   - Available commands reference
   - Custom task creation guide

3. **Integration** (1h)
   - Add justfile to git
   - Update CI/CD to use just commands
   - Add to contributor guide

**Justfile Example:**
```just
# Install ragged in development mode
install:
    python3.12 -m venv .venv
    .venv/bin/pip install -e ".[dev]"

# Run ragged CLI (auto-activates venv)
ragged *ARGS:
    .venv/bin/ragged {{ARGS}}

# Start Docker services
docker-up:
    docker compose up -d

# Run tests
test:
    .venv/bin/pytest

# Setup everything
setup: install docker-up
    @echo "Setup complete!"
```

**Files:**
- `justfile` (new, ~150 lines)
- `docs/tutorials/installation.md` (update)
- `.github/workflows/*.yml` (update to use just)

**Success Criteria:**
