## Deferred from v0.5.8

### LOW-1: Error Handling Improvements (1-2 hours)

**Priority:** LOW
**Category:** Code Quality

**Problem:**
- Some error handlers use try-except-pass without logging
- Makes debugging difficult
- Violates best practices

**Files Affected:**
- `src/security/permissions.py:230`
- `src/ingestion/config_validator.py:325`

**Proposed Solution:**
```python
# Before
try:
    risky_operation()
except Exception:
    pass  # Silent failure

# After
try:
    risky_operation()
except SpecificError as e:
    logger.warning(f"Operation failed: {e}", exc_info=True)
except Exception as e:
    logger.error(f"Unexpected error in operation: {e}", exc_info=True)
```

**Tasks:**
1. Audit all try-except-pass blocks
2. Add specific exception types
3. Add appropriate logging
4. Test error scenarios

**Success Criteria:**
- No try-except-pass without logging
- Specific exception types used
- Debug information preserved
