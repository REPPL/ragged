## Migration Notes

**No breaking changes** - All features are backwards compatible.

**New functionality:**
```python
# Query classification (new in v0.6.1)
from ragged.optimisation import QueryClassifier, RoutingMetadata

classifier = QueryClassifier()
classification = classifier.classify("How does ColPali compare to OCR?")

# Get routing recommendations
metadata = RoutingMetadata.from_classification(classification)
print(metadata.recommended_model)  # "llama3.2:70b" (complex query)
```

**Configuration:** No configuration changes required. Query classification works out-of-the-box.
