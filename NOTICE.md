# Notice

This repository is preserved as a historical reference.

## Purpose

ragged was a personal learning project used to explore Retrieval-Augmented
Generation (RAG) concepts. The learnings from this project informed the
development of [ragd](https://github.com/REPPL/ragd), the production implementation.

## Status

- **Not maintained**: No bug fixes or updates will be made
- **May not work**: Code may be incomplete, broken, or outdated
- **For reference only**: Use only for understanding development history

## Recommended Alternative

For a working RAG implementation, see [ragd](https://github.com/REPPL/ragd).
